# Related method: ADSM

Agent-Driven Software Management (ADSM) is related methodology for maintaining context and constraints around coding-agent work. It describes how a human can direct and review agent changes through explicit boundaries, validation, and reports.

ADSM does not define TeqFW. TeqFW is a modular JavaScript platform for web applications, and its explicit architecture remains useful whether or not a project adopts ADSM.

Continue with the [TeqFW ecosystem](https://teqfw.com/ecosystem.md), [philosophy](https://teqfw.com/ecosystem/philosophy.md), or [Showcase](https://teqfw.com/showcase.md). The [ADSM book](http://fly.wiredgeese.com/flancer/leanpub/adsm-en/) is optional related reading.
